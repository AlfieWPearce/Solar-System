# Side Projects

This directory contains experimental or exploratory work connected to the main solar-system simulator. Each project in here is self-contained, small in scope, and meant to help prototype ideas quickly without affecting the main codebase.

## Structure

- **three-js**
  Tests, prototypes, and learning exercises for using Three.js. This folder is where 3D experiments happen before being integrated into the main simulation.

## Purpose

Side Projects serve three main goals:

1. **Learning**
   A place to understad new concepts (lighting, cameras, controls,rendering pipelines)
2. **Testing Ideas Rapdily**
   Try new mechanics like first-person mode, orbital cameras, mini-maps, particle effects, etc.

3. **Keeping the main code clean**
   Experiments stay here so the main simulator remains stable and organised.

## How to Use

Clone the repository and run each porject independently.
Each subfolder contains its own `Readme.md` explaining how to run or extend that specific experiment.
